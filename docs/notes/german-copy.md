# German copy review (no native speaker available)

Every new German string is reviewed by an independent subagent before it ships; apply its fixes.

## Procedure
1. `node scripts/check-dict.mjs` (key + placeholder parity EN/DE).
2. Dump the NEW keys as `key<TAB>EN<TAB>DE` into `a scratch folder` (regex over `lib/dict/{en,de}/*.ts`).
3. a reviewer agent to a leaf reviewer: native German speaker, urban 25-45, regular DB rider; read-only; give the glossary, the placeholder meanings, where each string appears (390 px heading, share text, text drawn on a card) and ask for JSON `{key, severity: wrong|awkward|nit, current, suggested, why}` plus a 3-line verdict. Point out the specific risky rows.
4. Apply every fix in one small patch script (regex-replace by key), re-run check-dict, rebuild, re-check layouts: longer German can orphan words or overflow cards.
5. Tell the reviewer to also write its full JSON to a file under `a scratch folder` and return it: an async delegation result can arrive late or truncated, and the file is the reliable handoff (poll for it with a bounded loop; apply fixes from it with a regex-by-key patch script). If a result never arrives after an interrupted turn, re-dispatch instead of assuming it passed; when a late result for an already-applied batch shows up, compare it with what was applied and take only the new points.

## Glossary and tone (informal du, deadpan, no hype)
- "mindestens 15 Minuten zu spaet", Fahrt/Fahrten, ausgefallen, Fernverkehr / "Fahrten im Fernverkehr" (never "Fernfahrten"), Regionalverkehr, Strecke (not Verbindung: that is one journey in the DB app), Endbahnhof, "Verspaetungsquote" for a share label (not "Anteil verspaetet"), speichern for downloads, anzeigen for show/hide.
- Say "von X nach Y"; a route cannot "ankommen", trips do. Put the place before the participle ("in Berlin verspaetet"). Put the noun the sentence is about as the subject; avoid dangling colons plus bare numbers.
- When a sentence says a share is measured "per stop", word it so it cannot read as "late at every stop".
- DB's own punctuality rule is 6 minutes: show it beside the 15-minute figure.
- Echo the matched place name, not raw user input, in sentences with prepositions.
- Headings need a noun ("Abfahrten rund um {time}", not "Rund um {time}"); prefer "ab {station}" and "Uhrzeit" (not "Zeit") for departures and clock times; "sortiert nach" over "in der Reihenfolge von".
- Tiny batches work: a 2-string review returns in under a minute, so send new strings for review in the same turn as the feature instead of batching them for later.
- Connection-flow terms: the next train is the "Anschlusszug" (not "nächster Zug", which reads as the next departure by the clock); change time "Umstiegszeit"; "vom ICE 1541 in den ICE 240"; DB holding a train = "warten lassen"; destination filter "Alle Ziele"; time-of-day labels Egal / Morgens / Mittags / Abends / Nachts with the hours shown in the sentence. Links address the reader ("Sieh dir an, …", not "Zeig …").
- Flow-result labels: Geklappt / Verpasst / "Anschlusszug ausgefallen" (all participles, the legend and the per-train label must match); a failed change is "verpasst", not "nicht geklappt"; the history line is "Rückblick, nicht live" (not "Vergangene Daten"); "Alle Ziele" for the destination filter.
- Compensation vocabulary: Entschädigung, Fahrpreis, Erstattung, Zeitkarte, Servicecenter Fahrgastrechte, Schlichtungsstelle Reise & Verkehr, Eisenbahn-Bundesamt; a rights claim is an "Antrag" the rider "stellt"; the refusal grounds keep the Regulation's examples (Personen im Gleis, Kabeldiebstahl, Polizeieinsätze) and state what is NOT a reason (Streik der eigenen Beschäftigten).
- Compensation copy, second-round German findings: "Zielbahnhof deines Tickets" (not "Bahnhof auf deinem Ticket", which could be the start); a share is "Anteil der Fahrten, die ... erreichten, an allen {n} gemessenen Fahrten" (the plain "Anteil der {n} Fahrten, die ..." reads as all {n} being late); "nicht eingerechnet" for exclusions ("zählen nicht" clashes with a sentence saying a cancelled train does count for a claim); "widersprechen" for objecting to a refusal, matching the Beschwerde/Widerspruch steps; "Deutsche Bahn" in full in disclaimers; split long rights sentences for a phone. Third-round wording: the refusal ground is "nicht vermeiden und dessen Folgen sie nicht abwenden konnte" and "das Verhalten Dritter" (the Regulation's own phrasing, not the calque "eindämmen"); "die Unterbringung" for the capped hotel stay; "noch nicht geantwortet" for no reply after 3 months; "zählt weiterhin die planmäßige Ankunftszeit" instead of the calque "setzt die Uhr nicht zurück"; "in diesem Fall" on the taxi/plane exclusion so it does not read as absolute.
- Live-status wording: a predicted arrival is not a fact, so say "keine Verspätung gemeldet" / "no delay reported", never "pünktlich" / "on time" (DB often has no prediction yet, and the site defines late as 15+ minutes). Say the history above a live block "zeigt vergangene Fahrten" / "describes past trains": "sind Vergangenheit" and "are history" read as "obsolete". Status labels sit in a ~170 px column on a phone: keep each to two lines, and check the one that embeds a long station name ("Halt in {to} fällt aus") on a real long-name route.
- Typography: a non-breaking space (U+00A0) before % and € and inside "2. Klasse" in every German string; check by regex for a plain space before those, and keep the same in generated meta text. Keep meta descriptions near 155-160 characters.
- UI control labels: the two options of a sort toggle must be parallel ("Nach Uhrzeit" / "Nach Pünktlichkeit"; a bare superlative like "Am pünktlichsten" reads as a filter). Tabs next to nouns need a noun ("Nahverkehr", not bare "Regional"; ~110 px at 15 px fits 10 characters). Table row labels must not end in a dangling preposition ("Antragsfrist | 3 Monate", not "Antrag stellen innerhalb von | 3 Monaten"). Buttons lead with the verb ("Antrag stellen auf bahn.de": "Antrag auf X" means application FOR X). Name the reference point of relative times ("12 Monate nach der Fahrt", not "danach"; fix the EN "later" too). "Gegenrichtung" for the reverse direction; "Entscheidend ist" over "Es zählt"; trains "haben Verspätung", they are not "spät". NBSP between a number and "Min.".
- Review files live in (local probe script, not kept) (not scratch).
- Tell the reviewer that `suggested` must be the exact replacement string with placeholders only; once a reviewer wrote alternatives in brackets into `suggested` and the regex apply pasted them into the UI. After applying, grep the changed keys for `(`, `or`, quotes.
- Live wording: "wie spät" asks for a clock time; for delay say "wie viel Verspätung". A tiny label for an average reads "im Schnitt" (EN "on average"), not bare "üblich". A predicted arrival delay is "voraussichtlich {n} Min. später" after a colon. Plural subjects need plural nouns ("Abfahrten ... wie die DB sie meldet").
- Counts read "{ok} von {n} Mal" (not "{ok}-mal von {n}"); "Wenn der {a} hier früher … Verspätung hatte" over the calque "An früheren Tagen, an denen". Live forecasts: "aktuell {n} Min. Verspätung, Ankunft voraussichtlich {time}", "laut DB-Prognose". Time before place ("fällt heute hier aus"). Ask the reviewer to flag placeholder values that can be zero or negative; give those their own string.
- The most frequent reviewer finding is an English calque ("its own number", "this counts all pairs", a verb split from its particle by a long clause): write the German sentence from the meaning and keep the verb close to its subject.
